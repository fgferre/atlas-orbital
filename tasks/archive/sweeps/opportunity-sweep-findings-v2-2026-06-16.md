# Atlas Orbital — Opportunity Sweep v2 (2026-06-16)

**Rubric change (read this first).** Visual fidelity is now a **first-class pillar** alongside clarity, wonder, and trust — not something to be suspicious of. Atlas's visual target, Gaia Sky, is simultaneously an ESA-grade scientific instrument _and_ a stunning renderer, so "reference-grade render" and "scientific honesty" are the **same goal**, not a trade-off. Every fidelity idea below is judged by two gates. **GATE 1 — HONEST:** the detail must reflect real data or real physics (NASA/USGS textures & elevation, real photometry/B-V colors, real Rayleigh+Mie/Nishita scattering, real ephemerides); where it must approximate or fill a gap procedurally it **says so** in `VisualProvenance`/config JSDoc/CreditsModal, with the same discipline as the "not to scale" toggle — inventing a number and presenting it as measured truth = kill. **GATE 2 — ADAPTIVE:** it must be _additive_ on capable hardware and _degrade to a fast floor_ via `src/lib/qualityProfile.ts` + the `VISUAL_FIDELITY` tiers, so it never costs a learner reach. A feature that would regress the constrained tier is not killed — it is **tier-gated** (high path on strong HW, graceful floor on weak HW). An idea passing both gates is judged on net value (teaching, verifiable wonder, OR reference-grade credibility — a 14-year-old believing "this is real" and exploring more is a real payoff) and is **not penalized for being impressive**.

This v2 preserves all 50 surviving opportunities from v1, folds in the verified Codex corrections (several v1 "rejected — already exists" items were wrong: the value is half-built and undelivered, so they move into **Do now** as finish-work), and adds a new **Fidelity track** holding the render ideas that passed both gates.
