### Onda A: θ.1 — Star sprite kernel (fragment)

**Gaia Sky reference:**
 - `/tmp/gaiasky/assets/shader/star.group.quad.fragment.glsl`

**Atlas implementation:**
 - `src/components/canvas/Starfield.tsx` — `fragmentShader` constant
   (search for `void main` inside the template literal).
 - `src/lib/starfieldShaderMath.ts` — `starfieldCoreKernel`,
   `starfieldFragmentRgba` (executable TS mirrors).
 - `src/lib/starfieldShaderMath.test.ts` — pinned expectations.

**Math to compare:**
 - Core-kernel formula
   `clamp(1 - smoothstep(0, 0.04, 2·|uv - 0.5|), 0, 1)` — edges
   0.0 and 0.04 exact; smoothstep shape at off-midpoint samples
   (r=0.01 → 0.84375; r=0.03 → 0.15625).
 - Alpha composition: Gaia does `alpha = v_col.a * profile` then
   `fragColor = saturate(alpha * vec4(v_col.rgb + core * 2.0, 1.0))`.
   Verify atlas uses the same factor of 2.0 on `core` and the same
   alpha multiply on the full vec4.
 - Discard predicate: Gaia discards when `profile <= 0.0` AND also
   when `v_col.a <= 0.0`. Verify atlas discards both.
 - Premultiplied additive blend pairing: if atlas pre-multiplies
   rgb by alpha in the fragment, then `blendSrc/blendDst =
   OneFactor/OneFactor` is mathematically equivalent to Gaia's
   premultiplied alpha. Verify the pairing is consistent.

**Math to compare (exhaustive):**
 - `absMag = appMag - 5·log10(dist/10)` — exact formula from
   `AstroUtils.apparentToAbsoluteMagnitude`. Edge case: `dist<=0`.
 - `pseudoL = 10^(-0.4·absMag)`, `sizePc = sqrt(pseudoL) × 0.15`,
   with ceiling derived from the Java `min(..., 1e10)` internal-u
   literal (`1e10 / (PC_TO_M × ORIGINAL_M_TO_U)` ≈ 324.08 pc).
 - `a_size` (in vertex buffer) = `pseudoSizePc × DISTANCE_SCALE ×
   STAR_SIZE_FACTOR`. Verify factors applied in correct order +
   site (Gaia applies STAR_SIZE_FACTOR at buffer-write, not in
   pseudoSize).
 - Vertex `solidAngle = a_size / dist` literal (Gaia's small-angle
   approximation, documented as such in source comment).
 - `opacity = lint(solidAngle, u_solidAngleMap.x, u_solidAngleMap.y,
   u_opacityLimits.x, u_opacityLimits.y)` — VERIFY that atlas's
   `lint` helper uses smoothstep not linear.
 - `degrees12` / `radians12` precision wrappers around `pow` —
   `TO_DEG12 = 180e12 / π`, `TO_RAD12 = π / 180e12`. Verify the
   wrap is `clamp(radians12(pow(degrees12(sa), brightnessPower)),
   min, 3e-8)`.
 - Clamp range: `[minQuadSolidAngle, 3.0e-8]`. `3.0e-8` is a
   SOURCE LITERAL in the shader (NOT a uniform).
   `minQuadSolidAngle` is resolution-adaptive:
   `1.8e-9 × 1440 / backBufferHeight`.
 - `u_opacityLimits` default `[0.0, 1.0]` — verify against
   `config.yaml opacity: [0.0, 1.0]`.
 - `u_brightnessPower` default 1.0, allowed range [0.9, 1.1].
 - `u_sizeFactor` default: `starPointSize(=pointSize × 0.4 = 1.2) ×
   1e6 × pointScale(=1.0) = 1.2e6` with `pointSize = 3.0` from
   config.yaml.
 - `u_starBrightness` = `(brightness - MIN_STAR_BRIGHTNESS) /
   (MAX_STAR_BRIGHTNESS - MIN_STAR_BRIGHTNESS) × 4` with
   MIN=0.4, MAX=8.0, default brightness=2.22 → ≈ 0.9579.
 - `LEN0 = 20000` (scene units), boundary fade via
   `smoothstep(LEN0, LEN0×1000, dist)`; alpha null when
   `dist < LEN0`.
 - Proper motion applied BEFORE `dist = length(pos)`.
 - `gaiaBvToRgb` must be a 1:1 port of `ColorUtils.BVtoRGB`:
   * Ballesteros `t = 4600 × (1/(0.92·bv + 1.7) + 1/(0.92·bv + 0.62))`.
   * xyY polynomial branches by temperature range (1667-4000,
     4000-25000 for x; 1667-2222, 2222-4000, 4000-25000 for y).
     Verify coefficients exactly.
   * xyY → XYZ → sRGB matrix (three rows).
   * Gamma correction with `a = 0.5` (NOT 0.05).
   * Normalize by `max(1, r, g, b)` then `max(c / maxChannel, 0)`
     per channel.
 - `saturateStarRgb(rgb, 0.16)` HSV path: RGB → HSV, add 0.16 to
   S clamp [0,1], HSV → RGB.
 - Billboard-quad geometry: 4 verts at `[-0.5, 0.5]²`, indexed
   `[0,1,2, 2,1,3]`, UVs `[0,0, 1,0, 0,1, 1,1]`. Instance
   attributes `starPosition`, `velocity`, `a_size`, `starColor`.
 - Vertex billboard math: `viewPosition.xy += position.xy *
   quadSize` where `quadSize = solidAngle × dist × u_sizeFactor`.
   Verify atlas's quadSize formula matches Gaia.
 - `InstancedBufferGeometry.instanceCount` = catalog count;
   `frustumCulled = false` on the mesh node.

**Math to compare (exhaustive):**
 - Polar mask formula: `0.5 + 0.25·sin(dx·12 + t·2.0) + 0.20·cos(dy·37 - t·1.3) + 0.10·sin((dx+dy)·59 + t·1.6)`,
   then `(angular + 1.0) × 0.5`, then
   `minVal(=0.55) + (1 - minVal) × angular`, then add centre
   `smoothstep(0.85, 1.0, 1.0 - r)`, then final
   `clamp(angular + center, minVal, 1.0)`.
 - Spiral sampler: `dt = 3π / nSamples`, `fx(t,a) = a·t·cos(t)`,
   `fy(t,a) = a·t·sin(t)`, luma threshold 0.95 via `step`, bonus
   sample post-loop with `fy(t,a) × ar` (NOT `/ar`, NOT clamped).
   Final `lum /= nSamples`.
 - Halo-size formula:
   `size = u_textureScale × min(1.6, min(0.0001, viewAngle) × 5e5) × lum`.
   NOTE: the `min(0.0001, viewAngle)` clamps the INPUT to a max
   of 1e-4, meaning any solidAngleApparent > 1e-4 saturates the
   halo size cap.
 - `u_nSamples` default 1 (runtime-forced by
   `MainPostProcessor.updateGlow()`, NOT config.yaml's 10).
 - `u_textureScale = brightness × (glowFactor / 0.06) × 0.2 =
   2.22 × (0.055 / 0.06) × 0.2 ≈ 0.407`.
 - `u_spiralScale = brightness × pointSize × 0.5e-4 / fovFactor =
   2.22 × 3.0 × 0.5e-4 ÷ fovFactor` (at fovFactor=1 → 3.33e-4).
 - `fovFactor = tan(fov/2) / tan(20°)` applied to BOTH
   solidAngleApparent AND spiralScale.
 - `solidAngleApparent = rawSolidAngle × star.brightness /
   fovFactor` — rawSolidAngle is the PRE-shader-clamp value
   (pseudoSize/dist). Feeding the post-clamp value breaks the
   halo-size saturation math.
 - Light registry: `MAX_LIGHTS = 8` matches `#define N 8` in
   both shaders. Tier-nLights: 4/5/6/8 for low/normal/high/ultra.
 - NDC projection: Three's `Vector3.project` gives [-1, 1]; atlas
   rescales to [0, 1] via `(x+1)×0.5` to match Gaia's
   `auxV.x / w`.
 - Composer insertion: LightGlow is FIRST child of
   `<EffectComposer>` — matches `MainPostProcessor.java:227`
   (added to PostProcessBean before Bloom).
 - Gaia's fragment literal final line is
   `saturate(effectColor + scene.rgb)`. Atlas emits
   `clamp(effectColor, 0, 1)` with `BlendFunction.ADD` — this is
   documented intentional divergence for HDR preservation. Don't
   flag the additive choice itself; DO flag if atlas's
   clamp/additive math produces a different sum magnitude than
   Gaia's saturate(sum).
 - Reduced-motion gate: `<LightGlowSlot>` returns `null` when
   `state.accessibility.reducedMotion === true`. Verify no effect
   is mounted in that branch + no `useFrame` callback executes
   heavy work.

Part 3 — Documented intentional divergences (NOT drift)
================================================================

 1. **θ.1 / θ.1b vs billboard.stretch.glsl**: atlas uses
    screen-aligned billboard. Gaia's camera-velocity stretch is
    θ.1c (pending). Not drift.
 2. **LightGlow HDR ADD vs Gaia saturate-of-sum**: atlas emits
    `clamp(effectColor, 0, 1)` + `BlendFunction.ADD`. Preserves
    HDR for downstream Bloom. Documented in `LightGlowEffect.ts`.
 3. **LightGlow texture: gaussian vs Gaia `star-tex-03`**: real
    asset in `$GS_DATA`, not vendored. Conservative pure-radial
    gaussian used (equivalent to Gaia `textureIndex: 4`).
    Documented in `lightGlowSprite.ts`.
 4. **Fragment-stage spiral vs Gaia vertex-stage spiral**:
    correctness-preserving re-arrangement (computation is
    uniform-constant per frame). Documented in
    `LightGlowEffect.ts` class docstring.
 5. **Sun not in LightGlow registry**: Gaia filter is
    `Mapper.hip` billboard OR `Mapper.starSet`; Sun is planet/
    model. Atlas mirrors this. Not drift.
 6. **`@react-three/postprocessing` vs Gaia's own composer**:
    library choice. Only flag if effect-ordering produces wrong
    output.

Part 4 — High-risk math-drift categories
================================================================

 A. **Attribute semantic vs name.** `a_size` is pseudo-size not
    physical radius. Trace shader read → CPU write → catalog
    load → JavaDoc before trusting a name.
 B. **Runtime override hidden in init code.**
    `MainPostProcessor.updateGlow()` forces `setNSamples(1)`
    over `config.yaml samples: 10`. Look for similar patterns.
 C. **Pre-clamp vs post-clamp uniform feed.**
    `solidAngleApparent` must be PRE-shader-clamp × brightness.
 D. **FOV-factor plumbing.** `fovFactor = tan(fov/2) / tan(20°)`
    applied consistently.
 E. **Asset substitution drift.** Procedural fallbacks for
    `$GS_DATA` assets must be CONSERVATIVE (pure radial, no
    invented features).
 F. **Source-literal vs runtime-uniform confusion.** `3.0e-8`
    upper clamp must be inlined, not wired as uniform.
 G. **`lint` is smoothstep not linear.**
 H. **`degrees12` / `radians12` precision wrapping around
    `pow()`.**
 I. **pmndrs Effect mainImage signature order**
    `(inputColor, uv, outputColor)`.
 J. **Premultiplied blend pairing.** Fragment premultiplies by
    alpha; blend factors One/One. Verify the pair is consistent
    across θ.1 and θ.1b.
 K. **Unit conversions.** atlas `DISTANCE_SCALE = 206_265_000.0`
    (1 pc in scene units). Gaia uses internal units via
    `PC_TO_M × ORIGINAL_M_TO_U = 3.0857e7` per pc. Different
    scales are OK as long as `solidAngle = a_size / dist` is
    unitless (both in same scale) — verify the math always
    cancels.
 L. **Float32Array quantization.** When a Gaia constant
    (3e-8) is stored in a Float32Array uniform, fp32 may quantize
    slightly. Accept within ~1e-15 tolerance; flag if the drift
    is larger.
